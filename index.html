客户端下载与配置流程

配置流程是使用 PRPR橙 机场的核心步骤，请按顺序完成，通常只需几分钟即可开始网络加速。

第一步：选择套餐获取订阅

在官方网站选定适合的流量与设备数量套餐并完成开通，系统将生成专属订阅链接。请妥善保存该链接，后续客户端均通过它拉取最新节点。

第二步：下载对应客户端

Windows 用户可选用 Clash Verge 或 v2rayN；macOS 推荐 ClashX Meta 或 Surge；iOS 使用 Shadowrocket、Stash 或 Quantumult X；Android 使用 Clash Meta for Android 或 NekoBox。请从各软件官方发布渠道获取安装包，本站不托管第三方修改版以免安全风险。

第三步：导入订阅并更新

打开客户端，找到订阅或配置管理，粘贴 PRPR橙 提供的订阅地址，点击更新。成功后将出现节点列表，包含各地区普通线路与专线。

第四步：选择节点并开启代理

建议先进行延迟测试，挑选当前延迟较低、符合您目标地区的节点。开启系统代理或启用 TUN / 增强模式，使浏览器与应用流量走加速通道。首次使用可先访问常见网站确认连通。

第五步：日常维护

节点会定期更新，客户端可设置自动更新订阅。若遇个别线路波动，切换至其他节点或专线即可。流量与在线设备请在套餐范围内使用。

节点与线路说明

PRPR橙节点覆盖亚洲、北美与欧洲主要城市，普通线路适合日常浏览与视频，IPLC 专线针对游戏与实时通讯做了路由优化。我们持续监控线路质量并进行调整，不承诺某一时刻的绝对数值，但会通过工单优先处理旗舰与团队用户的反馈。用户可根据自己的位置与用途灵活切换，无需手动填写服务器参数。

官方推荐：需要游戏加速与全解锁流媒体的用户，优先考虑旗舰版年付方案，性价比更高且含优先支持。

常见问题

PRPR橙机场订阅是什么？如何使用？

机场订阅是一份自动更新的节点清单链接。您只需在支持的客户端中添加该链接并更新，即可获得全部可用服务器，无需逐条添加。PRPR橙官网开通套餐后即可查看专属订阅地址。

各系统客户端应该从哪里下载？

请使用各客户端开发者或官方商店提供的版本。本页配置流程中列出了常见推荐软件名称，下载后导入 PRPR橙 订阅即可。避免来路不明的破解包，以免账号与设备安全受到影响。

如何判断该选择哪条节点？

在客户端内运行延迟或速度测试，结合您访问的目标网站或游戏区服所在地区进行选择。同一地区可能有多条线路，遇到高峰可轮换尝试。旗舰版的 IPLC 节点通常更适合对延迟敏感的场景。

流量用尽或设备超限会怎样？

当月流量用尽后加速通道将暂停，次月重置或升级套餐后恢复。同时在线设备超过套餐上限可能导致部分设备无法连接或被踢下线，请按实际需求选择基础、旗舰或团队版本。

是否支持 Netflix、Disney+ 等流媒体？

基础版提供基础解锁，旗舰版与团队版强调全节点原生流媒体解锁，实际可用性会随平台策略变化。若某节点无法播放，切换至标注解锁的线路通常可以解决。

团队版和企业定制有何区别？

团队版面向多成员共用，提供更高流量、更多设备与 VIP 带宽节点，并含专属客户经理。企业如需定制分流规则或独立入口，可在开通后通过工单沟通需求。

连接失败时首先检查什么？

确认订阅已更新、本地时间准确、客户端权限（尤其是 VPN 配置与网络扩展）已授予，并尝试更换节点或重启客户端。仍无法解决时，旗舰与团队用户可走优先工单通道。
